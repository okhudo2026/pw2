# Практична робота №2 — Варіант 2 (Pets)

HTML/CSS верстка макета **Pets 1280px** із Figma. Структура: `index.html`, `css/style.css`, `assets/`.

## Перевірка
Відкрийте `index.html` у Chrome. Макет адаптується до ширини екрана.

## Git у наявному репозиторії labs
```bash
git checkout -b pw2
# скопіюйте папку pw2 з архіву до кореня labs
git add pw2
git commit -m "Practical work 2: Pets landing page"
git checkout main
git merge pw2
git push origin main
```

**Примітка:** верстка відтворює композицію на наданому скриншоті; логотипи партнерів та іконки є стилізованими текстовими замінниками, а не точними експортованими SVG. Блок відео є статичним прев'ю, бо відеофайл у матеріалах відсутній.
